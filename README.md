# xinbetween/homebrew-tap

Homebrew casks for [xinbetween](https://github.com/xinbetween) software.

```sh
brew install --cask xinbetween/tap/flowlight
```

## Casks

- **[flowlight](Casks/flowlight.rb)** — [Flowlight](https://flowlight.xinbetween.com/), a macOS network monitor that
  shows which app talked to which domain and keeps an eye on AI agents. Free and open source (GPL-3.0).

The casks point at the signed, notarized releases published by each project. The canonical copy of the Flowlight cask
lives in [xinbetween/flowlight](https://github.com/xinbetween/flowlight/blob/main/packaging/homebrew/flowlight.rb) and
is copied here on every release.
